# 🎯 Мои цели

## 🧩 1. Архитектурная чистота API

![API](https://img.icons8.com/fluency/96/api.png)

* Минимально достаточный код (KISS > абстракции)
* Отказ от лишних фабрик/хелперов
* Явные конфиги вместо “умной” магии
* Строгая предсказуемость JSON-ответов

Основание: регулярные требования к минимизации абстракций, прозрачности логики, строгим форматам ответов.

---

## ⚙️ 2. Контроль над инфраструктурой

![Network](https://img.icons8.com/fluency/96/network.png)

* Диагностика сети на уровне IP / ARP / TCP
* Понимание NAT vs WDS
* Исключение конфликтов IP
* Управляемая конфигурация роутеров

Основание: подробные технические разборы сетевой конфигурации.

---

## 🛠 3. Полный контроль над средой разработки

![IDE](https://img.icons8.com/fluency/96/source-code.png)

* WebStorm как основной инструмент
* Чёткая настройка editor launch
* Предсказуемость dev-workflow
* Минимизация лишних инструментов

Основание: приоритет WebStorm, устранение конфликтов переменных среды.

---

## 📦 4. Стандартизированные коммиты

![Git](https://img.icons8.com/fluency/96/git.png)

* Conventional Commits 1.0.0
* Короткие и структурированные сообщения
* Отсутствие “шума” в истории

Основание: явное требование к стилю commit-сообщений.

## 🗄 5. Явный SQL без сокращений

![Database](https://img.icons8.com/fluency/96/database.png)

* Без алиасов таблиц
* Полные имена (`users`, а не `u`)
* Прозрачность чтения запроса

Основание: прямое правило для SQL.

## 🧠 6. Максимальная техническая прозрачность

![Logic](https://img.icons8.com/fluency/96/mind-map.png)

* Без фантазий и предположений
* Чёткое указание источника данных
* Разделение фактов и догадок
* Отказ от асинхронных иллюзий

Основание: системное требование к честности и ограничению возможностей модели.
